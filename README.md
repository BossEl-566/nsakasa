# NsaKasa (Hand-Talk) 🇬🇭
### *Bridging the gap with 3D Ghanaian Sign Language (GSL) Interpretation*

**NsaKasa** is a mobile application designed to break communication barriers between the hearing community and the Deaf and hard-of-hearing community in Ghana. Developed as a final-year project at the **University of Ghana**, this app uses 3D avatar technology and real-time translation to provide a bridge for families, schools, and institutions to communicate naturally in Ghanaian Sign Language (GSL).

---

## 🌟 The Vision
In Ghana, many families with Deaf children face a "communication wall." **NsaKasa** (meaning "Hand-Talk" in Twi) aims to:
*   **Empower Families:** Provide a tool for parents and children to learn GSL together through interactive 3D modules.
*   **Institutional Access:** Enable hospitals, TV stations, and government offices to offer basic GSL translation via live speech-to-sign.
*   **Cultural Preservation:** Create a digital repository of GSL to ensure its unique nuances are preserved and accessible.

---

## 🚀 Features
*   **3D Sign Avatar:** Real-time rendering of GSL signs using an optimized 3D character for clear visibility of hand shapes and facial expressions.
*   **Speech-to-Sign:** Converts spoken English or Twi into GSL animations using advanced speech recognition.
*   **Interactive Learning:** A "Mirror Mode" or gamified interface to help hearing users practice and perfect their signs.
*   **Live Translation:** Designed for institutions (like TV stations) to provide instant visual interpretation.

---

## 🛠️ Tech Stack
* **Mobile Framework:** React Native (Expo)
* **3D Rendering:** @react-three/fiber (Three.js) for avatar integration
* **3D Models:** GLTF/GLB (Optimized for mobile performance)
* **Speech-to-Text:** OpenAI Whisper API (for real-time transcription)
* **State Management:** Zustand or Redux Toolkit
* **Backend:** Node.js / Firebase (for user data and sign libraries)
